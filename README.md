# Assembly: Endgame 🧠💀

A word guessing game built with React where the goal is to save programming languages before only Assembly remains.

🔗 **Live Demo:** https://matheus-braga6.github.io/react-assembly-endgame/

## 📚 About the project

This project was developed as part of the **Learn React** course by Scrimba.
It focuses on:
- useState hook for managing complex game state
- Component composition
- Reading and mapping static data from JavaScript files
- Array manipulation and conditional rendering
- Game logic and win/lose conditions

Players must guess the correct word before all other programming languages are eliminated, leaving only Assembly as the last survivor.

## 🛠️ Built with

- React
- JavaScript (ES6+)
- CSS
